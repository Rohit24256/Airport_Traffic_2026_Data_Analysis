# ✈️ Airport Traffic 2026 Data Analysis

## 📌 Overview
This project analyzes airport traffic data for January 2026 using Python.

## 🔍 Key Features
- Data Cleaning & EDA
- Visualization of flight trends
- Outlier Detection
- Linear Regression Model
- Hypothesis Testing

## 🛠️ Tools Used
- Python
- Pandas, NumPy
- Seaborn, Matplotlib
- Scikit-learn

## 📊 Insights
- Strong relationship between departures and total flights
- Traffic patterns vary daily
- Top airports dominate flight traffic

## 🚀 Future Scope
- Dashboard (Power BI/Tableau)
- Advanced ML models
